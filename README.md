# 🛒 বাজার দর (BazarDor)

### Your Daily Market Price Comparison Platform

## 📌 Project Description

**বাজার দর (BazarDor)** is a user-friendly platform that helps users explore daily market prices, compare product prices, and stay informed about rising and falling prices. It makes it easier to track essential grocery items and make smarter shopping decisions.

## 🛠️ Technologies Used

- **Next.js 16** – React framework for building the application
- **React** – Building reusable UI components
- **TypeScript** – Type-safe development
- **Tailwind CSS** – Styling and responsive layouts
- **DaisyUI** – UI components and themes
- **React Toastify** – Toast notifications
- **Git & GitHub** – Version control and project management

## ✨ Key Features

1. **Home Page:** Explore featured products and essential market price information.
2. **All Products:** Browse product cards with names, units, current prices, and price changes.
3. **Rising Prices:** Discover products whose prices have increased.
4. **Falling Prices:** Find products whose prices have decreased.
5. **Responsive Design:** Enjoy a consistent browsing experience on mobile, tablet, and desktop devices.

## 🎯 Project Goal

The goal of BazarDor is to make daily market price information easier to explore and help users make informed shopping decisions.
